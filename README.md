# My Path to Understanding AI 🧠

> One concept at a time. One laptop survived at a time. 🚫🖊️💻

This repository documents my journey into Artificial Intelligence.

I'm an iOS developer, and I started this project because I wanted to understand what actually happens behind AI systems — not just learn how to call an API or integrate an AI feature into an app.

My goal is simple:

> **Understand first. Build second.**

---

## Why This Repository?

When I started learning AI, I quickly discovered that knowing definitions wasn't enough for me.

Terms like *model*, *training*, *inference*, *weights*, or *neural network* only started making sense when I connected them through examples and questions.

So this repository is not meant to be a formal AI course.

It's a record of my learning process:

* the concepts I'm studying
* the questions that helped me understand them
* the examples that made things click
* the experiments I build along the way
* and, eventually, how I bring these ideas back into software development

Some concepts may be simplified at first and refined as my understanding grows.

That's part of the journey.

## How I'm Learning

I'm following a few simple rules:

**Don't memorize what I can understand.**

If I can't explain a concept in my own words, I probably don't understand it yet.

**Use examples.**

A simple Cats vs Dogs example can sometimes explain more than a page of definitions.

**Ask questions.**

Especially the apparently simple ones:

> What exactly is a model?

> What does the model learn?

> Where are the weights stored?

> What actually changes during training?

Those questions are often where the real learning starts.

**Experiment.**

Theory should eventually become something I can observe, test, break, and build.
