# Lesson 1 — Understanding the Foundations of AI

When I started learning Artificial Intelligence, I quickly realized that learning definitions wasn't enough.

I wanted to understand how the concepts connect.

What is AI?

How is Machine Learning different from traditional programming?

What does it mean for a model to learn from data?

And what actually happens between giving a model some examples and receiving a prediction?

This lesson follows the same path I used to understand these ideas.

## Parts

### [Part 1 — What Is AI?](./part-1-what-is-ai.md)

Artificial Intelligence, traditional programming, Machine Learning, and the first important difference between rules and learning from data.

### [Part 2 — Learning From Data](./part-2-learning-from-data.md)

Datasets, features, and labels — using simple examples with cars and Cats vs Dogs.

### [Part 3 — Training a Model](./part-3-training-a-model.md)

Supervised and unsupervised learning, training, generalization, training/test data, and overfitting.

### [Part 4 — From Training to Prediction](./part-4-from-training-to-prediction.md)

Inference and the complete journey from a dataset to a prediction, using the Cats vs Dogs example.

---

The goal is not to memorize definitions.

The goal is to be able to explain what happens in my own words.
